## 2. 主线台本：一条订单的一生

> 每步：**角色 · 页面 · 操作 · 台词要点**。⭐ 标记的是情绪高点。

### ① 销售下单
- **角色**：销售 · **页面**：销售 → 销售订单
- **操作**：新建订单 → 客户选 **CRAVE & COOK**(地址自动带出)→ 创建 → 逐行加商品:
  - **牛腩 BF-FLK-30 · 1 箱**(catch-weight,预估重量留空自动算)
  - **整鸡 CHK-WH-45 · 1 箱**(catch-weight)
  - 可再加 1-2 行干货(如香葱、芝麻油)做对照
- **台词**："客户按箱下单——注意肉类是按箱订、但最终按磅计价,干货是固定价,这套系统两种都支持。"

### ② 确认订单（三闸校验）
- **角色**：销售/经理 · **页面**：订单详情底部
- **操作**：点 **"确认并执行三重校验"** → 弹绿色 toast、按钮变 **"✓ 已确认 · 信用/毛利/库存三项通过"**
- **台词**："下单不是随便就能发货——系统一次校验**信用**(客户额度够不够)、**毛利**(利润够不够,否则要经理审批)、**库存**(有没有货)。三关都过才放行给仓库。"

### ③ 生成取货单并锁单
- **页面**：订单详情 → **"生成拣货单并锁单"**
- **操作**：点击 → 订单锁定(status→picking),生成取货单
- **台词**："一生成取货单,订单的价格数量就**冻结**了——仓库开始拣货时,销售不能再改单,避免拣的是移动靶。要加货就另开单、同趟配送。"

### ④ 取货
- **角色**：取货员 · **页面**：出库 → ① 取货
- **操作**：每行选周转筐(牛腩 A01、整鸡 A02),实拣件数 1 → 确认实拣 → **弹 toast,该行消失**
- **台词**："取货单告诉取货员**去哪个库位、拿哪个批号**。拣一个少一个,清空即完成。数量对不上必须填差异原因,不能静默短拣。"

### ⑤ 称重（⭐ catch-weight 高光）
- **角色**：取货员/称重员 · **页面**：出库 → ② 称重
- **操作**：按拣货单分组显示。**牛腩填 54.53、整鸡填 84.70** → 确认称重 → **弹 toast「已称重：牛腩 54.53 lb」,该行消失**
- **台词**(重点讲)："**这就是食品分销和普通 ERP 最大的区别**——客户订的是'1 箱牛腩',但牛腩每箱重量不一样。取货员上秤称出**54.53 磅**,系统**按 54.53 × 每磅价自动算钱**,不用人算、不会算错。整鸡同理。"

### ⑥ 生成发运单
- **角色**：仓库 · **页面**：出库 → 发运/装车
- **操作**：在"待建发运单"点 `PK-... · SO-... · CRAVE & COOK` → 生成发运单 → 点单号进详情
- **⭐ 发运明细页**：表格显示每行 **商品 / 批号 / 数量·实重 / 单价 / 小计**:
  - 牛腩 54.53 lb × $6.20 = **$338.09**
  - 整鸡 84.70 lb × $1.90 = **$160.93**
  - **预计应收 $499.02**
- **台词**："看,称完重的实际金额出来了——牛腩 338.09、整鸡 160.93,系统按实重算得清清楚楚。"

### ⑦ 放行装车（二次信用检查）
- **页面**：发运详情 → **"信用复核并放行装车"**
- **台词**："装车前**再查一次信用**——从下单到发货客户可能又下了别的单,第二道闸防止超额发货。"

### ⑧ 签收关单
- **页面**：发运详情 → 填签收人名 → **"确认签收并关单"**
- **操作**：签收后订单关闭(closed),库存扣减、预留释放
- **台词**："司机送到、客户签收,订单闭环——库存自动扣减,这批货正式出库。"

### ⑨ 应收落地
- **角色**：财务 · **页面**：财务 → 待开票队列
- **看到**：`SL-... · CRAVE & COOK · 重量完整 · $499.02`
- **⭐ 台词**："这就是终点——**从客户按箱下单,到取货称重按实重定价,一路到财务的应收账款 $499.02,全程自动、批次可追溯。** 这条链路你们现在的旧系统要么算错、要么卡死。"

## 3. 可选延伸（时间允许 / 客户追问时）

- **批次全链路追溯**：销售 → 历史订单 → "批次全链路追溯" → 任选一个批号,演示"3 秒双向追溯"(供应商→客户)。对比旧系统卡顿,是情绪高点。
- **退货退款**：一箱质量问题退货 → 隔离 → 退款/预存冲抵(同事的付款系统)。
- **权限**:IT → 用户管理,现场给某员工勾一个功能权限,其菜单实时变化(细粒度授权卖点)。
- **配送路线**:出库 → 配送路线,展示按路线固定配送日、客户站序(Phase A 地基)。

## 5. 应急 / 常见问题

- **称重页/取货页显示空**：确认订单已"确认+生成取货单";刷新页面。
- **加不了 catch-weight 行**：预估重量可留空(系统按均重算),或手填。
- **发运"待建"里重复点报错**：一拣货单只能建一张发运单;已建的不会再出现在待建(如仍出现请刷新)。
- **金额在订单页看不到**：正常——实重金额在**发运详情 / 待开票队列**显示,订单页显示的是下单预估。
- **想重跑一遍**：新建一张同样的订单即可;库存充足(每个 SKU 种了多箱)。
